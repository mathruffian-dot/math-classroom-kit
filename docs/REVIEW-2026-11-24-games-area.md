未 commit、未部署。基準 commit `d60e98c`。八上 3-2 課程由另一個 agent 平行製作（`docs/REVIEW-2026-11-24-g8-3-2.md`），不在本次範圍；本次只審平台。

## 老師的需求

1. 數感課堂的遊戲區要把魔王戰也放進來，讓老師「選單元」來玩。
   - 老師已決定：選單元＋選班級就開戰，學生照平常用班級代碼＋座號登入。
2. 十字交乘的對戰版要放進教學單元：先做 3-2 課程，在課程最後放「十字交乘對戰」頁，一按就開全班連線對戰。
   - 對戰版本來就有：全班連線對戰、雙人大屏對戰。

## 要特別審

- `game-raid` 用的 `POST /api/sessions` 會結束同班其他進行中的課（伺服器原有行為）。確認視窗的文字和流程是否足夠，有沒有誤結束的可能，例如兩位老師共用班級或多分頁。
- `startRaidGame` 的翻頁用 `slide` 控制指令：會關閉作答（`activityOpen=false`）。是否有副作用，例如原本在別頁開著的活動。
- `crossPanel()` 的重點預設：只在沒有對戰時用頁面 `focus`。老師在面板改了重點、或畫面重畫時，選擇會不會被蓋回去（`crossPanelKey`）。
- 學生在 `crossPage` 頁、還沒開戰時看到的畫面；開戰後切換作答卡（沿用 `view.cross` 的既有流程）。
- `gameUnits()` 的課程 ID 規則是否穩健（老師自建課程、AI 草稿不符合時會被略過）。
- 版面：遊戲區卡片 3 欄（1440 寬）；iPad 寬度未特別檢查。
