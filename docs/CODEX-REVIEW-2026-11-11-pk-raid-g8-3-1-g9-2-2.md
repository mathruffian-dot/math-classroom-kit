## 編號發現

### 1. blocker：正方形邊長把平方根固定選成正號，未限制 x

**位置**：`scripts/quiz-src/g8-3-1-raid.py:261` 的 `square_side()`，呼叫在第 344–346 行；`content/raids/g8-3-1d.json` 的 ultimate：

- `new-ultimate-正方形面積求邊長-66`：面積 $x^2+12x+36$，官方邊長 $x+6$。
- `new-ultimate-正方形面積求邊長-67`：面積 $9x^2+12x+4$，官方邊長 $3x+2$。
- `new-ultimate-正方形面積求邊長-68`：面積 $4x^2+20x+25$，官方邊長 $2x+5$。

**問題與反例**：題幹、附圖均未給 $x>0$，也未把 x 定義為某個正長度。分別取 $x=-7,-1,-3$，三題面積皆為 1，真實邊長皆為 1，官方選項卻皆為 −1。正方形確實存在，不能由「它是正方形」反推 x 必須為正。一般情況應取 $|ax+b|$，平方相等的核算不能取代邊長正值的檢查。

**建議修法**：三題題幹明示「已知 $x>0$」，讓目前的正號答案成立，維持本單元的公式分解練習；或另給足以保證 $ax+b>0$ 的條件。無須引入絕對值作為學生必須使用的新方法。修正時須讓來源核算也檢查定義域／正值條件。

### 2. blocker：作切線下一步題的完成圖直接提供答案

**位置**：`scripts/quiz-src/g9-2-2d.py:152` 的 `tangent_fig()`、第 182 行的 `tangent('step1')`、第 250 行 q7；`content/quizzes/g9-2-2d.json` 的 `q7-2`。同題被收進 `content/raids/g9-2-2d.json` shield 的 `g9-2-2d-q7-2`。

**問題**：題目問「連接 OP 之後，要以哪一條線段為直徑作圓？」但三個 variant 共用完成的作圖：虛線圓 Q 已通過 O、P，Q 明確在 OP 的中點，切點 M、N 與切線也都畫好了。學生直接讀圖就能選 OP，不必決定下一步。這不是標示某個已知角作為推理條件，而是把所問的作圖步驟本身預先呈現。

**確認證據**：已檢視既有 `artifacts/preview-2026-11-11-pk-raid/g9-2-2d-3.png`，頂排中央即此題；洩漏位於題目 SVG 本身，不是預覽頁的綠色答案或詳解。

**建議修法**：讓 `step1` 使用獨立的未完成圖，只保留原圓、圓心 O、圓外點 P 與 OP；輔助圓 Q、切點及切線留到公布答案後。同步改寫依賴尚未作出的 M 的干擾選項，避免選項指涉未定義點。`why90`／`why_tangent` 是問理由，可以使用完成圖，不必一併刪圖。

### 3. should-fix：半圓分析題的錯誤理由其實是真命題，卻不是充分理由

**位置**：`scripts/quiz-src/g9-2-2-raid.py:334` 的 `judge_semicircle()`，尤其第 351 行；analysis 的 `new-analysis-判斷＋理由：直徑所對的兩個角-1`、`-2`、`-3`，理由第 3 選項。

**問題**：「C、D 在直徑的兩側，所以兩個角互補」被指定為 False，但兩角各為 90°，確實互補；依前面已教的圓內接四邊形性質，這個敘述也成立。它單獨不足以推出兩角相等，所以本報告**不把它算成第二個完整的正確證明**，但目前會混淆「命題錯誤」與「理由不足」。學生選到真命題時被判錯，詳解也沒有說明不足之處。

**建議修法**：把干擾理由改成明確錯誤的完整推論，例如「兩角互補，所以一定不相等」；或明說題目要求能充分推出相等的理由，並在詳解解釋為何僅有互補不足。

**核算限制**：兩份 raid 的 `check_analysis()` 只檢查作者填入的 True／False 排列，未獨立推導理由真假；因此「全部核算通過」未攔下這個真命題。八上找錯題另有展開不相等的斷言，這是有用的核算，但仍不等於全部自然語句皆已受驗證。建議把可計算的真假轉成實際計算，對充分性另作人工審查。

### 4. should-fix：兩組 PK 題位在同一份試卷可能重複測同一組數字與同一計算

**位置與重複內容**：

- `scripts/quiz-src/g8-3-1a.py:199` 的 `q3-1` 與第 216 行的 `q10-2`：都是以 $x^2-5x-6$ 除以 $x+1$，求另一個因式 $x-6$。前者填商式的常數，後者選完整分解；已知數與主要計算完全相同。
- `scripts/quiz-src/g9-2-2d.py:244` 的 `q1-1` 與第 253 行的 `q10-1`：都是內接四邊形已知 ∠A＝70°，求／選 ∠C＝110°；後者改成判斷敘述，核心作答沒有增加推理。此組也隨 PK 收進 raid。

**問題**：雖然「題幹＋選項」不是逐字重複，兩題同時抽到時仍可直接沿用先前的結果，減少十題檢核的涵蓋效益。

**建議修法**：至少更換每組其中一題的數字；更好的做法是讓後一題需要不同的判斷，例如從已知商式判斷倍式關係，或分辨外角與內對角。另加同單元「相同已知數＋相同求量」的近重複檢查。

### 5. should-fix：八上普通攻擊含十題必須做多步直式的除法，與角色難度約定不符

**位置**：`scripts/quiz-src/g8-3-1-raid.py:43` 把 `g8-3-1a` 的 q1、q8 分入 attack；第 66–69 行再新增四題 `remainder()`。受影響的是匯入的 q1 三題、q8 三題，以及新增 attack 前四題，共十題。

**問題**：`docs/AUTHORING.md` 把 attack 定義成一步完成的基本運算；這些題幹卻明定「用直式計算」二次式除以一次式的餘式，含缺項補 0。要完成兩輪乘減，負號與對齊的負擔也高，並非一步記憶題。不能為了普通攻擊速度而改教餘式定理／代值捷徑。

**建議修法**：改分到較合適的應用池，attack 補入一步辨認餘式為 0、依已給除法結果判斷因式等題目，維持題量目標。這是分級／遊戲節奏問題，題目的直式方法本身合法，未因此列 blocker。

### 6. note：部分分析題與 PK variant 的認知需求不均

**位置**：`scripts/quiz-src/g9-2-2-raid.py:358` 的 `judge_central()` 三題；PK `g9-2-2a/q6`、`g9-2-2d/q7`。

**觀察**：`judge_central()` 只需回憶同弧圓心角是圓周角兩倍，理由再重述同一關係；相較找錯弧、平行弦、內接四邊形錯誤分析，破盾難度明顯較低。兩組 PK 題位的三個 variant 則分別考 SAS／SSS／條件、作圖理由／步驟／切線判定，不全是同難度的換數字題。

**建議**：未來可把較單純的比例回憶移至 shield，分析題加入兩個角所對弧是否相同的條件判讀。PK 可保留概念組題，但應承認其抽題難度差異，或拆成更一致的題位。這些不是數學答案錯誤。

## 抽核正常的內容與邊界

- **因式分解歧義**：`g8-3-1a/q5` 的反向等式雖代數上為真，題目考「因式分解的方向」，來源課程也明確區分展開與分解；不是兩個可接受的分解答案。`g8-3-1b/q5` 的部分提取式雖等值，但題幹明說提出「所有公因式」，因此不算第二個完整答案。未因因式順序可交換而發現兩個完整正解。
- **變號**：核對 c 的一次方變號、平方後負號消失、兩個負號、平方項再提公因式，以及 raid 找錯步驟；被指為錯誤的代數改寫確實不恆等，修正後恆等。包含 `wrong_block(3,1,-1)` 的負常數情況。
- **另一段弧**：`g9-2-2b/q6` 的 130°、100°、150° 對應 ∠ADC＝115°、130°、105°；D 在劣弧上，所對的是不含 D 的優弧，答案正確。相關 raid 算法／找錯題也使用補足整圓後除以 2。
- **對角／鄰角**：d 的 `neighbor(a,b)` 用 B 與 D 互補，沒有誤把 A 與 D 當對角；對角線分角與外角題的數字亦與公式一致。半圓例 4 的算法在 b 已由課程教過，未誤列為偷渡 c 的新定理。
- **同心圓**：度數依圓心角，弧長另看半徑。例：半徑 6、9，120° 時弧長為 4π、6π；長度差與敘述判斷均相符，未把弧長和度數混用。
- **範圍**：3-1a 的題幹／詳解以直式、商式、餘式、因式倍式為主；未要求餘式定理或綜合除法。產生器在幕後用 SymPy 的 `rem` 核算，不等於向學生教授餘式定理。3-1b／c 未要求 d 的公式分解；d 與 raid 未要求十字交乘、配方法或無理係數因式。2-2a 無圓周角，b 無平行弦／內接四邊形，c 無作切線；弧長、全等與切線垂直半徑皆有相應先備或當堂來源，未見必須使用 2-1 深層技巧才能完成的題目。
- **提示**：逐讀 36 題 analysis 的 hint，未發現直接寫出本題數值答案或正確選項編號。減號逐項變號、先找所對弧等屬規則允許的概念提示；不是因為提示能幫助排除錯項就一律當洩漏。發現 2 的作圖步驟則是所求結果本身已顯示，性質不同。
- **干擾選項**：多數能對應可診斷的錯法，例如把平方的係數直接抄進括號、括號只變一項符號、圓周角忘記除 2、直接對短弧除 2、把平行弦各自所對弧誤認相等。主要品質例外為發現 3、4、5、6。
