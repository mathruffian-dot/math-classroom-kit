# 魔王戰前「單元總測驗」（12 題）（2026-11-06，t46u）

## 給老師的結論
- 有魔王戰的那一堂，魔王戰**前一頁**多了一頁「單元總測驗」。順序：… → 課後檢核・PK 戰（這一堂 10 題）→ **單元總測驗** → 魔王戰。
- 玩法跟課後檢核・PK 戰完全一樣：可以**派全班測驗**（可前後翻、改答案、信心下注、時間到才公布答案），或**開 PK 戰**（隨機／同程度／點選／抽籤／搶答／配電腦、倒數、選了就鎖、答過才看到對錯）。
- 題目是**整個單元**各堂的課後檢核題庫抽 **12 題**，各堂平均出題；每次派題、每場 PK、「同組再戰」都重新抽。
- 畫面上都標「單元總測驗」：面板標題「2-3 單元總測驗」、大螢幕「2-3 單元總測驗（12 題）」、學生卡「單元總測驗 PK：你 vs 5 號」、CSV「單元總測驗／單元總測驗PK戰」，不會跟單堂的課後檢核搞混。
- 單元總測驗**不**列入「這一堂的錯題紀錄／派錯題練習」與「比上次進步」（題目範圍、題數不同，硬比會錯）；但每一題的作答會記進學習紀錄，並**對回原本那一堂的題型**（派回家作業時看得到是哪一堂的哪個題型弱）。

## 怎麼抽題
1. **單元分組（建置時）**：`scripts/build-lessons.mjs` 對有魔王戰的課程 id（例 `g8-2-3c`），取「去掉最後一個字母」的前綴 `g8-2-3`，找出 `content/quizzes/` 裡同前綴＋一個字母、且字母 ≤ 這一堂的課程（a、b、c）。寫進課程 `unitQuiz: { title, lessons }`——**只有課程 ID，不含題目**；並在魔王戰頁前插入 `unitQuizPage` 頁。建置時也檢查每一堂都存在且有題庫。
2. **開測驗時（伺服器）** `worker/quiz.ts` `drawUnitSlots`：
   - 名額＝min(12, 單元總題位)。各堂平均分 ⌊名額 ÷ 堂數⌋，某一堂題位不夠就給它全部、剩下的再平均給其他堂；最後除不盡的幾題**隨機給不同的堂**（例：5 堂 → 三堂 2 題、兩堂 3 題）。
   - 每一堂在自己的題位裡隨機抽、**同一題位不重複**；排序依上課順序（a→b→c），同一堂依原題號。
   - 單元總題位不到 12：全部出、不重複（測試涵蓋；目前四個單元都 ≥30，用不到）。
3. `drawUnit`：每個題位再從 3 題換數字的題目抽 1 題、打亂選項（同 `drawPaper`）。存進這一次的題庫**只留抽到的那 1 題**（卷子 variant 皆 0），每場約 1/3 大小，避免課堂快照變大（8 MiB 上限）。題位 ID 改成「課程 ID__原題位 ID」（例 `g8-2-3a__q4`），CSV 與學習紀錄用它對回原堂。

## 技術細節
- **型別**（`shared/types.ts`）：`Slide.unitQuizPage`、`Lesson.unitQuiz`、`QuizRun.unit`、`PkLobby.unit`。
- **驗證**（`worker/validation.ts`）：`unitQuiz.lessons` 1–12 堂、不可重複、須含這一堂；名稱 ≤90 字（加上「（12 題）」仍在題庫名稱 100 字上限內，備份還原不會失敗）。
- **伺服器**（`worker/app.ts`）：沿用間隔複習已有的 `run.bank` 機制。
  - `quiz-class` 帶 `unit: true` → 抽 12 題，`{ mode: 'class', unit: true, bank }`。
  - `pk-lobby` 帶 `unit: true` → 配對區記 `unit`；`pk-start` 依配對區、`pk-again` 依上一場決定是否用單元題庫，每場重新抽；配電腦（`makeBot`）用同一份 12 題。
  - `unitSources`：只用**同一位老師**的課程題庫（這一堂的課堂快照題庫除外）；**任何一堂找不到題庫就 409 不開**，不會偷偷只用剩下幾堂。
  - 單元總測驗不和單堂全班測驗比進步（`prev` 不給）、不進 `quizHistory`／`quizMisses`（原本 `if (run.bank) continue` 就跳過）。
  - 順手修：`quizRecord` 的 PK 戰績原本對所有 PK 都用這一課的題庫算分；單元 PK 有 12 題、配電腦時會讀到第 11、12 題而 503。改成 `runBank(bank, run)`。
- **學生端不外洩**：題庫（`bank`）師生都不送；學生的 `run` 白名單只多了 `unit`；答案／解析的公布規則與課後檢核相同（全班測驗鎖定後、PK 答過的那題）。課程 JSON 給學生的 `unitQuiz` 只有名稱與課程 ID。
- **學習紀錄**（`worker/homework.ts`）：單元 run 依題位 ID 第一個 `__` 切開，對到原堂題型（`g8-2-3a:q4`）。
- **前端**（`src/main.ts`）：`unitScope()` 決定面板／大螢幕是單元還是單堂（配對中、進行中看那一次；否則看目前頁面）。單元頁不顯示單堂的錯題紀錄與「派錯題練習」；按鈕 `data-testid`：`unit-quiz-class`、`unit-pk-lobby`。
