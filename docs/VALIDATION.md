### 本機自動化測試（通過）

- **`npm run lessons`**：5 份課程通過驗證，0 錯誤、0 提醒。
- **`npm test`**：22 項單元測試全部通過。涵蓋：
  - 教師密碼（預設登入、修改、鎖定）
  - API key 只存在伺服器端，不出現在任何回應、快照或備份

  - 兩層批改；AI 平行投票在佇列外執行並寫回課堂狀態

  - 運算式引擎拒絕惡意輸入
  - 純文字算式轉 LaTeX
  - 即時推送的內容依身分隔離（學生只收到自己的作答、公布前看不到答案）；登出後連線會被關閉
- **`PW_CHANNEL=msedge npm run test:e2e`**：13 項全部通過，使用獨立的教師、iPad、手機瀏覽器 context：
  - 師生裝置都使用即時連線（WebSocket）；老師翻頁後，學生在 5 秒內沒有發出任何輪詢請求，畫面仍同步換頁。
  - 學生依序完成操作題、數值題（抽「答對」）、手寫畫布題。
  - 手寫題先做第 1 層判對錯並發回，再做第 2 層依規準給分並發回；學生端看到紅筆疊圖；其他學生看不到。
  - 5 份課程的每一頁，在 1920×1080、820×1180、375×667 三種尺寸下都沒有頁面捲動或水平溢位，而且課本截圖都能載入。
  - 教材編輯器預覽可用；AI key 存檔後頁面與 API 都不會回傳金鑰。
