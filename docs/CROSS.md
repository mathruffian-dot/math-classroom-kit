# 十字交乘・大板操作（八年級 3-2）

獨立的課堂活動，不是課程頁。老師在大螢幕或 iPad 上操作，學生不用登入。
第二階段會加「全班連線對戰版」，伺服器端共用同一個產生器（`shared/cross.ts`）。

## 怎麼打開

- 教師登入 → 側欄「**遊戲**」（`#/games`）→「十字交乘（大板操作）」卡片 → 按 **L1／L2／L3**。
- 直接開網址：`#/games/cross?level=2`。要固定題目（示範、測試）加 `&seed=123`；同一個 seed 一定出同一串題目。加 `&pool=N` 把每一輪的題池縮成 N 題（示範「出完重新開始」、測試用）。
- 和其他教師頁一樣要先登入：沒登入打開 `#/games/cross` 或 `#/games` 會回到登入頁（e2e 有測）；學生帳號登入後一律進學生畫面。
- 右上角「全螢幕」按鈕把整個板子放大到全螢幕。

## 畫面與操作

- 上方是題目（KaTeX 排版）；左邊是十字圖，右邊是卡片匣，底下是回饋列與老師按鈕。
- **十字圖四格**：左欄是 x 係數（上 p、下 r），右欄是常數（上 q、下 s）。每一列就是一個因式：(px+q)、(rx+s)。
  - 紫色斜線＝左上 × 右下（p·s），藍色斜線＝左下 × 右上（r·q）。
  - 讀數即時更新：兩個交叉乘積、交叉相乘和與目標（一次項係數）、兩欄各自相乘是否等於 x² 係數與常數項（✓／✗）、目前拼出來的因式。
- **放卡片**：
  - 拖曳（Pointer Events，觸控、滑鼠、觸控筆都可以）：拖到格子放下；拖回卡片匣就收回。
  - 點選：先點卡片（橘色框），再點格子；點已放好的卡片再點卡片匣＝收回；選了卡片再點已放好的卡片＝換位置。鍵盤：Tab 到卡片按 Enter（選取中的卡 `aria-pressed="true"`），再 Tab 到格子按 Enter；格子裡的卡按 Delete（或 Backspace）放回卡片匣，焦點留在那張卡；Esc 取消選取。卡片的讀屏名稱會說出它在哪一格。
  - 放到已經有卡片的格子：兩張交換（從卡片匣來的話，原來那張回卡片匣）。
  - x 係數卡（紫框、斜體 2x）只能放左欄，常數卡（藍框、+3）只能放右欄；放錯欄會提醒，不會放進去。
  - 拖曳中途被打斷一律作廢、卡片留在原位：老師按下一題／換等級／清空／公布答案／提示／提出公因數，或系統送出 `pointercancel`、`lostpointercapture`。拖曳中其他手指按卡片不理會。每題的卡片 id 帶題目序號（`q3-c0`），舊題的指標碰不到新題的卡。
  - 每張卡在卡片匣有固定的「家」，拿走後留下虛線框；格子大小固定。放卡片只搬動那張卡的節點、更新讀數，不重畫整個板子，拖曳中 `touch-action: none`，畫面不捲動、不跳動。
- **回饋**（不洩漏答案）：
  - 四格滿且正確：十字圖變綠、「✓ 正確！」並寫出完整的因式分解（L3 含公因數 k）。
  - 交叉和不對：「✗ 交叉相乘和 = −5，目標 +5，差 10」。
  - 兩欄相乘不對：「✗ 左欄相乘 = 4，要等於 x² 的係數 6」／「✗ 右欄相乘 = 6，要等於常數項 −2」。
  - 顏色之外都有 ✓／✗ 文字。
- **老師按鈕**：
  - 清空：卡片全部回卡片匣，可以重做（同一題重做不再加分）。
  - 提示（漸進）：L3 還沒提公因數時先提示「三個係數的最大公因數、負號一起提」；之後第 1 次亮出正確的兩張 x 係數卡（L1 左欄固定，直接跳到第 2 次），第 2 次亮出正確的兩張常數卡並說明正負，第 3 次四張都亮。提示文字直接寫出發亮的數字（例「2x 和 3x」「−1 和 +2」），不只靠顏色。
  - 公布答案：把正確的卡片放進四格（黃色），L3 會一起顯示提公因數那一步；不加分、連對歸零。
  - 下一題：換一題。同一場、同一等級從題池依序出題，題池用完前不重複；用完時回饋列提示「這個等級的 N 題都出過了，重新洗牌開始新的一輪」，換一個種子再來一輪。
  - 等級 L1／L2／L3：馬上換成該等級的新題。
  - 自動升級：勾選後，連續答對 3 題（`CROSS_AUTO_STREAK`）按「下一題」會升一級（最高 L3）。
- 右上角顯示「答對 n 題・連對 m」。

## 等級

| 等級 | 題型 | 例 |
|---|---|---|
| L1 | x² 係數 1；左欄固定是 x、x，只放常數卡 | x²+5x−14 = (x+7)(x−2) |
| L2 | x² 係數不是 1、正的，三個係數互質 | 6x²+x−2 = (2x−1)(3x+2) |
| L3 | 要先提公因數 k（k ≠ 1，可能是 −1、−2…，首項是負的就一起提） | 2x²−2x−24 = 2(x−4)(x+3)、−x²+x+6 = −(x−3)(x+2) |

L3 一開始十字圖是鎖住的，要先按「提出公因數」，畫面顯示 `原式 = k(括號裡的三項式)`，再對括號裡的三項式做十字交乘；目標也是括號裡的一次項係數。括號裡的 x² 係數可能是 1（左欄固定 x、x）或不是 1。

## 出題規則（`shared/cross.ts`）

- 題目：`ax²+bx+c = k(px+q)(rx+s)`，全部整數。`inner = (a,b,c)/k` 是本原三項式（`gcd = 1`、首項為正）。
- **符號規則**：左欄 p、r 一律是正數（x 係數卡只有正數），正負號全部放在常數；整個式子的負號由 k 提出。所以 (−2x+1)(−3x−2) 這種寫法不出現，要寫成 (2x−1)(3x+2)。
- 判定 `crossJudge(item, fill)`：接受任何數學上成立的填法（p·r = a'、q·s = c'、p·s + r·q = b'，p、r > 0），回傳 `{ ok, complete, products: [p·s, r·q], sum, target, diff, leadProduct, constProduct, leadOk, constOk, reason }`。第二階段伺服器端也用，所以對任何輸入都嚴格：
  - 空格是 `undefined`／`null`。左欄固定（`leadLocked`）時左欄可以省略、填 `null` 或 `1`；明確填了別的數就判錯（例：x²+5x−14 填 2、3、7、−2）。原因看 `item` 有沒有帶 `cards`：沒帶 `cards` → `reason: 'lead'`；帶了 `cards`（板子上的完整題目）→ 左欄固定時沒有 x 係數卡，填的數不是卡片，`'card'` 優先，回傳 `reason: 'card'`。
  - 不是安全整數（小數、NaN、字串…）→ `reason: 'invalid'`。
  - `item` 帶 `cards` 時，每個數字都要是該欄種類的卡，同一張卡不能用兩次 → 否則 `reason: 'card'`。內部三項式本原，因此成立的填法只有標準答案和「上下兩列對調」——單元測試把每題所有卡片擺法都列舉驗證過。
- 範圍（一律作用在**原式**的係數，L3 也是）：|a| ≤ 12、|b| ≤ 30、|c| ≤ 60。L3 提出 k 之後，括號裡的限制是 a′ ≤ ⌊12/|k|⌋、|b′| ≤ ⌊30/|k|⌋、|c′| ≤ ⌊60/|k|⌋。L1 的常數 |q|、|s| ≤ 12，L2 ≤ 9；x 係數拆法 p ≤ 6。單元測試對每級 3000 題斷言 |a| ≤ 12、|b| ≤ 30、|c| ≤ 60。
- 不出：b = 0、c = 0、完全平方、兩個常數相同（q = s，卡片會重複）。
- 可重現：`crossItem(seed, level)` 用 mulberry32；`crossSeed(場次種子, 等級, 第幾題)` 算每題的 seed；`crossSequence(場次種子, 等級, 題數)` 依序產生且同一場不重複。第二階段可以給每位學生不同的種子。
- 題池：`crossPool(場次種子, 等級, 大小)` 依 `crossSeed(…, 0, 1, 2…)` 收集不重複的題目，第一題就是 seed 0 那題。大小 `CROSS_POOL_SIZE`：L1 200（範圍內全部的題目，單元測試列舉核對）、L2 150、L3 150。板子從題池依序抽題，用完才開新一輪（第 2 輪起用 `crossSeed(場次種子, 等級, 1000000+輪次)` 當種子，第一題避開上一題）。

## 卡片與干擾卡

- 左欄固定（x² 係數 1）：6 張常數卡＝正解 2 張＋干擾 4 張。
- 要放 x 係數卡：8 張＝x 係數正解 2 張＋干擾 1–2 張，常數正解 2 張＋干擾 2–3 張。
- 常數干擾卡的順序：
  1. **正負號放反**：−q、−s（一定有一種擺法兩欄乘積都對、交叉和剛好是 −b；q = −s 時對調兩張常數就是這個陷阱）。
  2. **常數的其他拆法**：例如 −14 的 14、−1、1、−7、2…（小的優先）。
  3. 不夠時補相近的數（q±1、2q…）。
- x 係數干擾卡：a' 的其他拆法（6 → 1、6）；a' 是質數時補一張拆不出來的數。
- 干擾卡彼此不同、也不和正解同數字；x 係數卡全是正數。
